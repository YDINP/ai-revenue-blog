2026년 7월 16일, 중국 문샷AI(Moonshot AI)가 새 모델 Kimi K3를 공개했습니다. API와 앱이 먼저 열렸고, 전체 가중치는 7월 27일 공개될 예정입니다. 주목할 점은 규모입니다. 2.8조 파라미터 MoE(전문가 혼합) 구조로, 지금까지 공개된 오픈웨이트 모델 중 가장 큽니다. 무엇이 달라지는지 검증된 사실 기준으로 정리했습니다.

## Kimi K3, 숫자로 먼저 본다

가장 먼저 짚어야 할 건 규모입니다. Kimi K3는 **2.8조(2.8T) 파라미터 MoE** 모델이고, 네이티브 멀티모달(비전)을 지원하며, **100만 토큰 컨텍스트**를 처리합니다. 오픈웨이트 모델 중 이 정도 규모가 공개된 적은 지금까지 없었습니다.

| 항목 | Kimi K3 |
|------|---------|
| 파라미터 | 2.8조(2.8T), MoE |
| 컨텍스트 | 100만 토큰 |
| 멀티모달 | 네이티브 비전 지원 |
| 가격(100만 토큰, 입력/출력) | $3 / $15 |
| 추론 모드 | 상시 켜짐(별도 추론 전용 변형 없음) |
| API·앱 공개 | 2026년 7월 16일 |
| 오픈웨이트(가중치) 공개 | 2026년 7월 27일(예정) |
| 독립 벤치마크 종합 순위 | 4위 |

컨텍스트 100만 토큰은 코드베이스 전체나 긴 문서 뭉치를 한 번에 통째로 넣을 수 있는 수준입니다. 여기에 파라미터 규모까지 최대라는 건, 단순히 "크다"가 아니라 오픈웨이트 진영이 최상위권 모델과 경쟁할 수 있는 근거가 하나 늘었다는 뜻입니다.

## 가격 — 출력 토큰이 GPT-5.6 Sol의 절반

실제로 체감이 큰 부분은 가격입니다.

Kimi K3는 100만 출력 토큰당 15달러, GPT-5.6 Sol은 30달러입니다. 입력 가격도 K3가 3달러로 Sol의 5달러보다 낮습니다. 긴 대화나 대량 생성 작업처럼 출력 토큰 소비가 큰 워크로드에서는 이 차이가 그대로 비용 절감으로 이어집니다.

## 4위권이 갖는 의미

독립 벤치마크 종합에서 Kimi K3는 4위를 기록했습니다. Claude Fable 5, GPT-5.6 Sol에만 뒤지고, Claude Opus 4.8은 앞섰습니다. 최상위 두 자리는 아니지만, 오픈웨이트 모델이 폐쇄형 최상위권과 벤치마크상 격차를 크게 좁혔다는 의미입니다.

여기서 "오픈웨이트"라는 조건이 중요합니다. Claude Fable 5나 GPT-5.6는 API로만 접근 가능한 폐쇄형 모델입니다. Kimi K3는 7월 27일 가중치가 풀리면 자체 서버·온프레미스 환경에 직접 올려 돌릴 수 있습니다. 데이터를 외부로 내보낼 수 없는 환경, 특정 도메인에 맞춰 파인튜닝이 필요한 환경, 벤더 종속을 피하고 싶은 환경에서는 이게 벤치마크 순위 자체보다 더 실질적인 차이를 만듭니다.

## 상시 추론 모드 — 별도 변형이 없다

또 하나 눈에 띄는 설계는 추론입니다. Kimi K3는 "thinking mode"가 기본값으로 항상 켜져 있습니다. GPT나 Claude 계열이 종종 일반 모델과 추론 전용 모델을 나눠 내놓는 것과 달리, K3는 하나의 모델이 기본으로 단계적 추론을 거쳐 답을 냅니다. 사용자 입장에서는 어떤 변형을 고를지 고민할 필요 없이 하나의 엔드포인트로 추론 성능을 얻는 셈입니다.

## 개발자 입장에서 정리하면

- **직접 돌릴 수 있다.** 오픈웨이트 공개(7월 27일) 이후엔 API 비용 없이 자체 인프라에서 실행 가능. 대량 호출이 잦은 서비스일수록 장기 비용 이점이 큽니다.
- **출력 비용이 싸다.** 100만 출력 토큰당 $15는 GPT-5.6 Sol 대비 절반. 긴 답변·대량 생성 워크로드에 유리합니다.
- **컨텍스트가 넉넉하다.** 100만 토큰이면 대형 코드베이스나 긴 문서를 통으로 넣는 작업에 부담이 적습니다.
- **성능은 4위권.** 최상위는 아니지만 Opus 4.8을 앞서는 수준이라, "오픈웨이트라서 성능을 포기한다"는 공식이 더는 성립하지 않습니다.

## 결론

Kimi K3는 지금까지 공개된 오픈웨이트 모델 중 가장 큰 2.8조 파라미터 MoE 모델이면서, 독립 벤치마크 4위라는 성능까지 갖췄습니다. 여기에 출력가가 GPT-5.6 Sol의 절반이라는 가격 경쟁력, 100만 토큰 컨텍스트, 상시 추론 모드가 더해집니다. API·앱은 이미 열렸고, 7월 27일 오픈웨이트가 풀리면 직접 인프라에 올려 쓸 수 있는 선택지가 하나 더 생깁니다. 폐쇄형 최상위권을 계속 쓸지, 오픈웨이트로 옮겨 비용과 통제권을 가져갈지 고민하는 시점이라면 지켜볼 가치가 있는 모델입니다.
